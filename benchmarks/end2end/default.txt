# BF16, one per model and node count, in two families. Every case trains on 262,144 tokens per GPU
# per step (64 sequences of 32K, or 512 of 4K, per node), synthetic and packed, with force-balanced
# routing. EP is as large as the deployment allows (ep8, ep16, ep32 on 1, 2, 4 nodes, never above
# a model's expert count) and PP only where a model does not fit without it. Each config was chosen
# by a fit search keeping peak memory under 115 GB (82% of an H200). Configs whose search is still
# running are listed as comments. FP8 cases follow in a later pass.

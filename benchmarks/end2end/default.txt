# The default set: what launch.sh runs when it is given no case. Realistic training configs in
# BF16, one per model and node count, in two families. Every case trains on 262,144 tokens per GPU
# per step (64 sequences of 32K, or 512 of 4K, per node), synthetic and packed, with force-balanced
# routing. Each config is the fastest measured layout (tokens/s per GPU) with peak memory under
# 115 GB (82% of an H200): a fit search set CP (32K) or the micro-batch (4K) at the largest EP the
# deployment allows (ep8, ep16, ep32 on 1, 2, 4 nodes, pp1, pp2 only where a model needs it), then
# a tuning pass measured multi-node configs at pp1-ep8 (EP inside a node), pp2 and the other EPs,
# re-fitting the knob. workspace/benchmarks/end2end/TUNING.md records every layout tried. Configs
# still searching are listed as comments. FP8 cases follow in a later pass.
